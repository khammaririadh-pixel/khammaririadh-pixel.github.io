# Wortflug · Deutsch lernen

A free German course app (A1–B2): animated lessons and scenes, grammar overview and verb tables, ~1,100 words with English and Arabic, mixed training, and Lena, a voice conversation partner (including free talk on any topic).

Install: open the GitHub Pages link in Chrome (Android) or Safari (iPhone) and tap **Install app** / **Add to Home Screen**.

Voices: the device's German voice, Gemini natural voice with your own key, and meSpeak.js / eSpeak (GPL) as a last resort. Speech input uses the browser's speech recognition.
